## What it is

Site em Movimento is a skill for Claude Code (and Codex) that builds a site whose top is a continuous video: the camera moves forward as the person scrolls the page. The video is generated by AI in short chained clips, and scripts check that there are no jumps between them. Below the film, each section gets an animation made in code that explains what it says. It is for anyone who wants an opening page that feels like a movie. You need Claude Code and, if you want real video, a video generator (Kling, Agnes, Kie or another); without a generator, it builds everything in code.

> Not to be confused with **filmarca**, which does the opposite (turns an existing site into a brand film).

## Install

```bash
git clone https://github.com/inematds/site-movimento ~/projetos/site-movimento
ln -s ~/projetos/site-movimento/skill/site-movimento ~/.claude/skills/site-movimento
bash ~/.claude/skills/site-movimento/tests/motores-contrato.sh     # 4/4 engines OK
```

Then, in Claude Code: `/site-movimento` with your references attached.

## Video engines

| Engine | Authentication | Pins start and end | Measured |
|---|---|---|---|
| `kling` | `kling` CLI through the subscription | yes | 30 credits per 5 s clip at 720p |
| `agnes` | `AGNES_API_KEY` | yes | built and tested against the contract |
| `kie` | `KIE_API_KEY` | depends on the model | built and tested against the contract |
| `custom` | `MOTOR_CMD` (any AI) | depends | n/a |
| code | none | n/a | zero cost |

## Pilot numbers

- 3 clips + 1 loop on Kling 720p: 150 credits (one loop redone for being too still).
- Frame pinning between 0.91 and 0.997; zero hidden cuts; 361 frames; continuity PASS.
- Maximum stutter of 33 to 36 ms on scroll (it was 150 to 315 ms before fixing the bitmap window).

## Measured delegation

Building pieces with taste stayed with the stronger model (8 of 10 approved blind against 2 of 5 for the
smaller model). The three critics gave the same verdicts on both models. Details in
[`skill/site-movimento/referencias/7-delegacao.md`](skill/site-movimento/referencias/7-delegacao.md) (in Portuguese).
